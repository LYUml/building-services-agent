LICENSE.honeybee-radiance and licenses/ retain installed upstream license/notice texts; dependencies.json records versions/license metadata. Restore with bootstrap.ps1. See ../../docs/HONEYBEE_SCENE.md for exact source/native bindings, execution, optical/grid checks and incomplete-scene/annual-simulation limits. No native Radiance executable is launched by this worker.
