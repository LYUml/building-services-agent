# GIS context adapter

Original thin pyproj/PROJ coordinate conversion. requirements.txt and dependencies.json pin the isolated runtime; licenses/ retain installed pyproj/PROJ, certifi and parent Shapely/GEOS notices. Restore with bootstrap.ps1. Parent polygon/plot dependencies are pinned in the project's gis optional extra.

See ../../docs/GIS_CONTEXT.md. Actual source snapshot/replay supports 2D historical footprints only; county height metadata discovery is not an executed 3D integration. Public data retains its own source terms and attribution, separate from library/code licenses. No generated environment or source dataset is redistributed here.
