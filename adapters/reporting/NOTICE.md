# Reporting dependencies

ReportLab 4.4.9 provides PDF layout; Pillow 13.0.0 and charset-normalizer 3.5.2
are pinned installed dependencies. pypdf 7.0.0 provides independent text checks.
Licenses copied from installed distributions are retained here; existing pypdf
attribution remains applicable. No upstream engine code is rewritten.

The caller supplies a font path. Font files are not redistributed; rendering records
the supplied font hash. Check the font's permitted use for the intended delivery.
