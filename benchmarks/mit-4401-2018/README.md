This is one real course-project bundle with four related precursor assignments. It is not two independent completed designs. See NOTICE.md for attribution/license, sources.json for pinned originals, requirements.json for 21 preliminary grouped obligations and basis-review.json for quantity classes/decisions/gaps. This review does not replace the complete source documents or claim semantic coverage is finished.

Stage unchanged sources and a blocked all-passage plan with:

```powershell
.venv/Scripts/python scripts/stage_public_brief_benchmark.py --out runs/new-public-brief
```

For a locally cached source directory add `--cache runs/public-brief-intake-v1/sources`. Both download and cache paths require exact reviewed hashes. New output directories only; no completed coursework is used. Source PDFs live only in ignored run directories.
