# mep-electrical

For selected Hong Kong phase-current balance after numerical analysis, route through ../mep-regulations/SKILL.md and docs/HK_PHASE_BALANCE.md. Use an independently sourced protective-device rating, four-wire/single-phase-load classification and justified RMS design/model basis; the numerical study's current target is not a breaker rating. Fundamental phasor results alone cannot clear harmonic/neutral requirements. The three_phase_regulations workflow task must inherit the drawing study producer and gate it through requires_pass; full electrical conformity remains unestablished.

For calculation-bound three-phase schematics and phase schedules after a passing workflow study, use docs/THREE_PHASE_DRAWINGS.md and `bsa.three_phase_drawing`. Supply the actual workflow task directory and evaluated Graphviz path; optional AutoCAD performs guarded copy-only SAVEAS, independent reopening and measured paper-scale plotting. Inspect the actual PDF separately and retain image/source hashes. Keep schematic paper positions distinct from source route lengths; no protection or cable selection is supplied. Workflow kind three_phase_drawing inherits an earlier three_phase task with explicit --graphviz/--autocad paths. Missing tools, failed study and changed producer bytes block drawing; replacement project inputs are forbidden. Native output still needs separate actual page and engineering review.

For a single-voltage three-phase constant-PQ wye network, use docs/THREE_PHASE_NETWORKS.md and the isolated pinned pandapower runtime through `scripts/run_three_phase.py`. Explicit source sequence data, per-phase electrical kW/kvar, line sequence impedances/lengths and current/voltage study targets are required. Inspect independent branch/node/complex-power checks and native input correspondence in study.json. A converged target failure remains fail; source-hash association does not verify interpretation. Workflow kind three_phase invokes this adapter with explicit --three-phase-python and retains failed targets/missing runtime as downstream blockers. Straight saved-IFC correspondence is available through three_phase_ifc (docs/THREE_PHASE_IFC.md); connected electrical BIM remains pending. This path does not cover physical neutral/harmonics, transformers, protection, motor starting or Hong Kong conformity. Do not treat its study targets as verified cable ratings or feed its loads into the single-phase project format below.

Use docs/PROJECT_FORMAT.md. Populate equipment and circuit data from the brief, inspected geometry, measured routes and authoritative references. CLI: bsa validate <project.json>; bsa run <project.json> --out <new-run-directory>.
The calculation engine uses sum(kW/PF)*1000 for connected VA, demand VA / line-neutral V for Ib, tabulated ampacity times correction factor for Iz, and mV/A/m * Ib * route /1000 for voltage drop. Mixed load VA summation is conservative scalar aggregation, not a phasor solution. This slice covers single-phase circuits only; do not map three-phase loads to it.
Review Ib <= In <= Iz and voltage drop, then independently address fault disconnection, breaker breaking capacity, overload conventions, coordination, neutral/harmonics, incomer demand and earthing as applicable. No table values are embedded; cite chosen coefficients and conditions. Failed checks require changes, not an unchecked report.

For full installation-path voltage drop and jurisdiction checks use ../mep-regulations/SKILL.md and docs/ELECTRICAL_PATHS.md. `electrical_regulations` derives the supported single-phase feeder/branch budget directly from original inputs; branch-only results are insufficient. Retain explicit origin/topology, shared downstream loads and coefficient sources, and never clear failed branch protection because a selected voltage-drop rule passes. Full feeder protection and three-phase analysis remain unsupported by this adapter.

For supported TN bolted-fault checks, read docs/ELECTRICAL_FAULTS.md and use `electrical_fault` or `bsa.electrical_fault` with explicit fault source data for every circuit. Keep minimum hot L-PE loop current separate from maximum prospective fault at the device. Require actual nominal-voltage/current applicability, total-clearing and full-interval let-through energy guarantees; do not infer B/C/D defaults or I2t from prospective current squared times trip time. Null/uncovered data stays pending. CPC thermal area alone does not select a compliant conductor; source k/time limits, mechanical minima, actual editions/clauses and remaining protection/earthing gates separately.
DXF is a metre-coordinate overlay. It does not prove native DWG fidelity or lighting photometry. For native AutoCAD work, verify active document full path immediately before every write; use a versioned copy. Prove units, layers, scale and a three-device sample with actual save/reopen and plot review before mass placement. Keep unsaved user documents open; do not restart CAD.
Generate schedules and diagram labels from the same IDs. Reconcile geometry counts with device data after native authoring.

For pump operating estimates, read docs/PUMP_ELECTRICAL.md and use `pump_electrical` only with explicit pump/source-port GUIDs, electrical ID, centre-position basis and operating PF. For saved straight cable geometry use workflow three_phase_ifc with depends_on on the exact three_phase study, explicit ifc and binding paths, and no replacement project. Gate three_phase_drawing with requires_pass on this check when geometry correspondence is required. The reader checks saved native solids, Axis, placed ports, source hashes and electrical lengths; it does not derive a new study, select cables or establish actual electrical connections. Preserve failed swept-disk evidence and require mandatory solid validation; the verified fixture uses explicit circular extrusions. Direct/transitive gates from another numerical producer are rejected.

To recalculate from changed straight IFC lengths, use bsa.three_phase_ifc_project in docs/THREE_PHASE_IFC.md. Extraction may tolerate only old length differences, never changed Body/Axis/ports/anchors or invalid solid checks. Workflow kind three_phase_ifc_project registers this producer; downstream geometry, rules and drawing inherit the new project and fresh study together. Failed numerical targets remain fail.
