# Hong Kong base fan-power rule

## Native rectangular design-flow denominator

Workflow `rectangular_fan_regulations` now inherits a passing rectangular_model_design or rectangular_network_binding and takes basis/pack/sources. It accepts no replacement network, model, IFC or numerical report. Basis uses the existing fan facts/edition contract but must omit supply_design_airflow; a provided override is rejected. A sourced true network_represents_supply_design_flow assertion is separately required: a subnetwork's total cannot silently stand for the whole system design supply.

The adapter rederives numerical geometry from the source model, independently inspects saved hollow walls and reconciles saved ports, verifies the numerical report's exact input hash, and recomputes flow/pressure before deriving L/s. It preserves native/numerical target failures. Producer/check artifacts are pinned by the workflow. A rectangular drawing may require this rule only when both consume the same native producer. This binds the denominator, not electrical motor data, native fan inventory, fan operating point or whole-building meaning; those remain independent sourced assertions and review items. Generic facts-only checks remain distinct.

Six official-source-backed native tests cover real execution, denominator override, changed report/profile, missing power and a wrong-producer drawing gate. Four binding, nine fan-table, seven coverage and four model-design regressions also pass (30 distinct tests). Evidence: evidence/hk-fan-power/native-flow.json. Earlier native-flow-binding-pending notes are superseded only for this scoped denominator path.

Select `hk-fan-power-2026.11.10` explicitly. It covers only the conditioned-space CAV/VAV unadjusted path of [EMSD BEC 2024](https://www.emsd.gov.hk/beeo/en/pee/BEC_2024_ENG.pdf) clauses 6.7.1–6.7.3 and 6.7.5 (printed 24–25 / PDF 30–31). Base limits are 1.6 and 2.1 W per L/s respectively. The strict below-2500 W exemption and separately sourced AHU/Schedule 2 exemption assertions produce not_applicable, never whole-HVAC approval. Exactly 2500 W is not below the threshold.

[EMSD TG-BEC 2024](https://www.emsd.gov.hk/beeo/en/pee/TG-BEC_2024.pdf) 6.7(a)(i), printed 76 / PDF 87, clarifies clean-condition electrical power drawn by supply/return fan motors; nameplate output and delivered air power are different. The adapter requires sourced inventory, clean-power and supply-design-flow basis confirmations. Do not use duct pressure, thermal kW, nameplate output, or Q*pressure as this electrical metric. This module does not determine a fan operating point.

The supported path assumes the clean treatment-device pressure drop does not exceed 250 Pa and claims no deduction. Higher/unknown drop stays pending for separate assessment; no pressure-to-watts subtraction is performed. Reduced-speed/fresh-air control under 6.7.4, mechanical ventilation under 6.7.6, actual statutory scope/edition, deductions and full HVAC acceptance remain pending.
