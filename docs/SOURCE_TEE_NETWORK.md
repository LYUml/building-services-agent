# Source tee network integration

`bsa.source_tee_network` integrates the actually authored source tee candidates
into a fresh copy of the selected finite-elbow backbone. Original inputs and
models stay unchanged. Use the explicitly selected host `BSA_PROJECT_ROOT` for
external coursework; documents cannot select a workspace.

```
python -m bsa.source_tee_network run SOURCE_TEE_RUN --out FRESH_NETWORK_RUN
python -m bsa.source_tee_network verify FRESH_NETWORK_RUN
```

The source must pass the existing independent tee-candidate verification and its
original native DWG/source/radius ancestry. Every original unequal tee remains
represented, including blocked nodes. Unattempted source connection classes and
original requirement IDs remain explicit. The inherited minimum straight
remainder is unchanged. Blocked fittings neither consume straight length nor
receive fabricated connections.

The adapter deducts each actually authored tee reach from the correct source
straight endpoint, after the original elbow trims. Both ends are accounted for
before authoring. It reuses the existing BIM author, native rectangular solid
checks and reference-storey export. A negative remaining-length result stops.

Official pinned IfcOpenShell `project.append_asset` imports the existing verified
local components. Existing source worlds and owned-port frames are restored;
actual source-to-sink connections are rebuilt from source identities. External
cap positions, opposing normals and rectangular width/height roll must agree.
The final saved IFC retains native body representation and property fingerprints,
world frames, owned port identity, exact link coverage and unified ventilation
system/reference-storey containment. Schema/EXPRESS checks execute on the result.
Verification reconstructs the trimming from original source data and independently
compares the saved model to the verified component sources.

This is partial physical topology, not a complete installation design. Full raw
clash/clearance analysis is a separate required check, including new components.
Physical product joints, sheet-normal taper construction, equipment/architecture,
fitting pressure losses and complete engineering/regulation acceptance remain
pending. Existing source dimensions, construction assumptions and missing inputs
are not upgraded into measured facts. CLI exit 2 preserves incomplete design
scope even when the recorded native/integrity checks pass.

## Executed source study

The real external project run integrates all 14 actually authored local tee
assemblies through 42 source interfaces. Its saved model has 99 native bodies,
212 owned ports, 90 actual directed links and 32 boundary ports. Independent
source/native replay passes; the original 33 requirement identities remain.
ROOT stays blocked and two source multi-branch nodes remain unattempted. The
original backbone and existing DWG/PDF deliverables are unchanged.

The same original raw clash policy, with zero contact waivers, was executed on
the new saved IFC. Geometry coverage passes. Unique intersection pairs reduce
from 38 to 10 (20 raw intersection records remain). Clearance still fails:
93 raw violation records represent 66 unique pairs. These records include new
interfaces; counts must not be compared as if the represented inventory were
unchanged. No tolerance or contact exemption was changed to make them pass.
The remaining intersections involve original source straight bodies, not a
claim that all represented installation requirements have been satisfied.

Nine source/native regression tests pass. Separate saved-model controls reject
deletion of an actual connection and a 10 mm body displacement. The replay is
an observed CLI result, not authenticated third-party certification. See
[safe aggregate evidence](evidence/source-tee-network.json).
