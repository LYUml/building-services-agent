# Source-network pressure evidence ledger

```
python -m bsa.source_pressure_ledger run FITTING_ANALYSIS --out FRESH_OUTPUT
python -m bsa.source_pressure_ledger verify OUTPUT
```

Use explicit host BSA_PROJECT_ROOT for external project data. The new thin
adapter reuses source_fitting_data verification and original duct_chain_analysis
boundary paths. Existing per-outlet source-table subtotals already exist; this
adds an independent identity/arithmetic reconciliation and actionable shared
missing-evidence map, not another pressure solver or replacement correlation.
No new dependency, coefficient table or protected public dataset is introduced.

Each outlet retains actual directed fitting/straight identities, signed
conditional source contributions, null numerical gaps and interface joint-review
counts. The ledger checks original requirement identity, exact request/table
correspondence, duplicate/unused/missing paths, affected-outlet coverage and
agreement with both upstream subtotal records. Parallel outlets are not summed.
Missing values never become zero. Even a numerically populated path retains
physical/transcription, whole-fitting friction/station, interaction/joint,
terminal/equipment and boundary-pressure gaps. Separate transition end-straight
studies stay excluded. No complete pressure, critical path or fan duty is inferred.

Missing numerical paths are ordered by descending affected outlet count, then
stable model IDs. This is a source-research priority, not hydraulic criticality
or a set of waived engineering obligations. Known signed subtotals are neither
lower bounds nor complete fan pressure requirements.

Two tests exercise signed shared paths, independent parallel outlets, null
contributions and excluded end studies; rejection controls cover wrong affected
outlets, duplicate identity, fabricated subtotals/completeness, NaN, missing
requests and altered requirements. Durable test receipt verifies. The CLI keeps
exit2 and design_accepted=false while engineering remains incomplete.

Actual source-bound generation and independent saved-ledger reconstruction both
execute: 20 outlet paths, 76 unique fitting paths, 31 conditional numerical
values and 45 numerical gaps, with all 33 requirements retained. The largest
missing-data path affects 12 outlets. All 31 separate transition end studies
remain excluded. Full pressure/critical path/fan duty stay unresolved. Only
aggregate evidence is public; protected sources and actual ledger remain in the
selected coursework workspace.
