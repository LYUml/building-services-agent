# Hong Kong building drainage: source research

The demand tools currently calculate scoped quantities; they do not establish a compliant sanitary network. Keep Buildings Department aboveground building drainage requirements distinct from Drainage Services Department public sewer design and from WSD potable-water requirements.

The official [PNAP APP-164](https://www.bd.gov.hk/doc/en/resources/codes-and-references/practice-notes-and-circular-letters/pnap/APP/APP164.pdf), retrieved2026-11-11 with printed November2023 revision, is pinned in [source evidence](evidence/hk-drainage-source.json). Paragraph2(d)/(e) distinguishes buildings over3 through20 storeys from buildings over20 for separate pipework at the stack/manhole discharge level. The latter also addresses the floor above. Footnote5 distinguishes total building height from storeys served by a particular stack, with special podium/basement scope.

The classroom's ground-floor exclusion is not a universal all-height rule. Determine the actual building scope, discharge level, connected floors and fixtures before DU aggregation. Paragraphs3/4 and the appendices require separate works-type/application review; current document availability alone does not establish a project's applicable edition.

`bsa.drainage_scope.separate_discharge_floors` now provides a tested planning helper for 2(d)/(e). It returns relative floor offsets from the stack's manhole-discharge floor: [0] for more than3 through20 storeys and [0,1] above20. The discharge floor is not assumed to be ground level. Supply total building storeys, or an explicitly selected podium-only/basement-only scope and its count; stack served-floor count is not a substitute. Counts at or below3 remain outside the supported height bands, without implying exemption from other requirements.

Edition, works-scope and survey evidence are mandatory nonempty reviewed references. Unknown scope/count/evidence yields pending and no floor selection. The helper does not fetch or authenticate those references, decide legal applicability, verify fixture inventories, select actual floor labels or inspect pipe routes. Its tests cover 3/4/20/21 boundaries, special scopes, missing evidence and invalid counts. No new dependency or rule engine was introduced.

`bsa.drainage_connections` now reviews declared individual sanitary-fitment connections for one stack. For selected floors both `connected_to_stack=false` and `separate_to_manhole=true` are required. Known violations remain failed even with an incomplete inventory. Unknown floor or connection facts remain pending; fixtures outside selected floors receive no acceptance check. An empty list can pass this limited check only with explicit complete-inventory confirmation and a source reference. No separate pipe per fitment is inferred: Figure6 allows the two lowest-floor pipeworks to combine subject to other requirements.

Run `python -m bsa.drainage_connections project.json --out runs/new-review/result.json`. The exact project fields are `scope`, `fixtures`, `inventory_complete`, `inventory_source`, `references`, `official_reference`. `scope` holds the planning helper's keyword arguments. Each fixture has exact fields `id`, `floor_offset`, `connected_to_stack`, `separate_to_manhole`, `source`. Offsets are integer storeys relative to the manhole-discharge floor, or null; connection and completeness facts are Boolean or null. References map relative file paths to SHA256 hashes; `official_reference` names the APP-164 reference with the pinned November2023 bytes. Inventory/edition/works evidence strings should identify supplied pinned survey/decision records; the program checks bytes but cannot authenticate their interpretation. The output pins sources and scope/check code. Existing output paths and changed sources are rejected. CLI exit2 always retains whole-design acceptance as pending.

Four connection tests plus four floor-selection and six demand/workflow tests pass. A local synthetic study using the pinned official PDF separately executed positive, prohibited-stack, unknown-connection and wrong-source cases with the expected pass/fail/pending/rejection. These are method controls, not actual building observations or completed coursework.

No generic APP-164 conformity rule pack, saved-model binding or full sanitary design is claimed. This review is not yet connected to the generic regulations workflow or DU inventory. Cross-ventilation, offsets/restricted zones, traps, roof outlets, pipe capacity, current Drainage Regulations and other applicable requirements remain unresolved. The official PDF stays in ignored runs; source bytes and exact references are recorded without republishing a course document.
