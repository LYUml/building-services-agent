Its official basis is [EMSD Wiring CoP 2025](https://www.emsd.gov.hk/filemanager/en/content_443/COP_E_2025.pdf#page=190), 25C(1)(h), printed page 189 / PDF page 190. The heading is on PDF 189. The table page was text-inspected and rendered; a fresh official download matches SHA256 d69ae0c53972cc583de64b8e83ca7428460419b7f06ffa2f4f3db79e7b165c3b.

For the selected LV PVC-insulated stranded-copper path, the internal-radius factors for non-armoured cable are 3D at D≤10 mm, 4D at 10<D≤25 mm and 6D above 25 mm. Armoured cable uses 6D. D is overall cable diameter, and the radius is internal, not centreline. Adjacent 25C(1)(i) refers HV installation to manufacturer recommendations, so this implementation does not clear HV cables. The [official edition notice](https://www.emsd.gov.hk/en/electricity_safety/new_edition_cop/new_edition_cop_electricity_wiring_regulations/index.html) has a qualified 2020 transition route through 2026-12-31; project edition selection remains explicit. The selected table does not replace 15G(c)'s no-damage requirement or manufacturer instructions.

## Reused rule engine and source contract

`bsa.cable_bend_rules` extends the existing versioned `bsa.regulations` evaluator through method pvc_stranded_copper_bend. It uses the existing official-source hash, edition, jurisdiction, applicability and review/pending mechanisms; no new engine/dependency is introduced. Unknown classification or units stay pending. Explicitly unsupported construction/HV is outside this selected path and cannot produce a passing gate. A short-radius numeric result is review_required, not an assertion of whole-project statutory noncompliance.

The static evaluator takes sourced Boolean facts wiring_scope_confirmed, low_voltage, pvc_insulated, stranded_copper and armoured, plus overall_diameter and internal_bend_radius quantities in mm. Test boundaries include exactly 10 and 25 mm, armoured sizes, just-below-limit values, changed source bytes, missing edition and unknown classifications. The 1e-9 mm comparison allowance is floating-point roundoff only; it is not a construction or measurement tolerance.

`bsa.cable_bend_regulations` binds saved geometry through the existing native IfcOpenShell/Manifold electrical reader. It derives internal radius from checked centreline radius minus circular envelope radius. The basis requires explicit actual-overall-diameter correspondence, not an assumed interpretation of a nominal or generic envelope. The declared actual diameter must match the saved parameter within numerical roundoff; inconsistent geometry fails. Native BSA_CableSelection ProductReference and SourceSHA256 must match the selected classification source. Missing metadata remains pending. These are source-association checks, not independent authentication of product documents or electrical ratings.

The basis JSON has exact top-level fields version, sources, jurisdiction, rule_pack, edition_decision and bends. Sources use relative path, sha256, locator and kind; edition_decision has edition and a known source. Each bend row has source, product_reference, overall_diameter_mm, overall_diameter_is_actual, wiring_scope_confirmed, low_voltage, pvc_insulated, stranded_copper and armoured. Unknown values use null, not guessed defaults. Every saved bend requires a row. All provenance, geometry, pack and official inputs are hashed and rechecked; old rule packs remain unchanged.
