# Source-native component and parameter schedules

source_network_schedule joins existing verified fitting/native analysis into a
readable HTML schedule and full-precision JSON. It reuses source_fitting_data
verification/native_case, original source-network/flow calculations and pinned
IfcOpenShell identity/properties. Standard JSON/HTML output adds no dependency or
engineering engine. Existing ifc_drawing schedules only its supported straight
profile contract; view_tags assumes bounded circular/straight contexts. Neither
is silently applied to all compound-network fittings.

```
python -m bsa.source_network_schedule run FITTING_ANALYSIS --out FRESH_SCHEDULE
python -m bsa.source_network_schedule verify FRESH_SCHEDULE
```

Use explicit host BSA_PROJECT_ROOT. Source records cannot select the workspace;
outputs are fresh and outside immutable fitting analysis. Verification replays
source/native/table ancestry and independently reconstructs JSON and HTML from
original model/analysis, checking complete artifact/source/method correspondence.
Domain exit2 keeps engineering acceptance pending, including on successful checks.

One N-tag is assigned per sorted native product GUID, independent of duplicated
names. Every port keeps its actual owned GUID/direction, source section/node,
model clear dimensions, inherited design-flow classification and calculated
velocity/velocity pressure. Tags are stable for this model identity set, not
promised across changed model identity sets. Drawing tag placement is separate;
this schedule does not modify CAD/BIM or claim installed annotation acceptance.

Lengths distinguish saved straight extrusion, native circular Axis arc and
transition axial extent. Junctions get no guessed unique route length. Separate
retained-straight friction and conditional developed-end studies remain separate;
signed fitting values, actual reference ports, source locations, applicability
notes and missing evidence survive. Null losses remain null. Complete pressure,
critical path and fan duty are not inferred. Source nominal-clear-size, physical
scale, elevation, gauge and air assumptions remain visible and source-linked.
