# Tagged native-network delivery through MCP

The fixed-host MCP interface reuses the existing source_network_tag_pipeline
through the isolated JSON worker and pinned official MCP SDK1.30.0. No new
optimizer, CAD engine, engineering solver or dependency is introduced.

- bsa_run_tagged_network_delivery(delivery,schedule,out)
- bsa_inspect_tagged_network_delivery(out)

All paths are relative to the host-selected project root. The host supplies
BSA_PROJECT_ROOT and --autocad at startup; client tools cannot choose executables
or replace the root. Strict unknown argument rejection applies. Production
requires fresh separate output; missing host AutoCAD blocks producer execution.
The entry starts from an existing source-native delivery and parameter schedule,
not an arbitrary brief. Missing complete finite tag placement blocks native work.

The producer places all model GUID tags and creates actual DWG/reopened export/
PDF before independently reconstructing graphic checks, original source
ancestries and their common analysis identity. Inspection independently replays
the complete saved package. The compact summary binds component counts, pending
scope and actual delivery/DWG/PDF identities; the inspector rejects a changed
record across replay. Returned project_path is directly usable by the existing
bsa_render_source_page tool when the host also supplies --pdftoppm. Compare its
source hash to the inspected PDF, then actually inspect the returned image.

Generation/inspection may each take several minutes. Configure adequate client
read timeouts; a lost observation does not prove process termination. Image
return is not automatic visual review. Producer plot review stays pending,
pressure_budget_complete and design_accepted remain false. Physical source
calibration, full pressure/equipment/product/installation and engineering
acceptance remain unresolved. Named desktop-client setup and arbitrary MEP
design are separate acceptance needs.

Targeted controls exercise real protocol schemas, missing host runtime,
attempted runtime overrides, outside-project reads, artifact identity changes
and record mutation during inspection. Public evidence contains aggregate
results only; source models, coursework, native drawings, client logs and page
images remain in the explicitly selected project workspace.
