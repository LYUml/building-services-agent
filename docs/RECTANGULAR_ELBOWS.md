# Native rectangular 90-degree duct walls

## Saved chain pressure binding

The existing rectangular_network_binding now supports source-defined level straight/90-degree bend chains. Use examples/rectangular-air/elbow-chain-plan.json, or elbow-coordination-plan.json to add represented-model clash checks. The source network omits bound geometry and, for any chain containing bends, aggregate minor_k. Every piece explicitly declares LocalLossCoefficient and LocalLossBasis `excess over centreline Darcy friction`; even an assumed zero on a straight piece needs a source. This prevents combining a pre-aggregated K with per-piece losses or counting bend Darcy friction twice. No circular-fitting correlation is automatically applied to a rectangle.

Source port-chain checks preserve coincident directed links, constant inner dimensions, aligned width/height face directions and opposite outward normals. Saved inspection independently verifies each straight/bend wall, port positions/normals, actual circular Axis length, source radius/dimension/K metadata and connected node/route references. The native pressure input sums straight distances plus true quarter-arc length. Hydraulic diameter/local actual rectangular velocity and the upstream friction solver remain unchanged. Nonlevel air paths still reject under the existing level-pressure contract.

Source geometry_scope is `axis-aligned envelopes and rectangular straight and elbow walls`; the bend's body_shape is `rectangular 90-degree elbow wall` and class is IfcDuctFitting. Existing straight rectangular walls are also valid in that explicit scope.

Supply independently sourced InternalWidth_m (radial section dimension), InternalHeight_m (normal to the bend plane), WallThickness_m and CenterlineRadius_m, plus arc_center_m, two perpendicular signed cardinal bend_axes, an exact outer envelope and two actual arc-end ports. R must exceed half the radial outside width. Width/height follow the bend frame; joining a straight piece requires compatible section roll/orientation, not just matching two numbers. No implicit fitting K or manufacturer product is assigned.

The thin adapter reuses pinned IfcOpenShell 0.8.5 native [IfcRevolvedAreaSolid](https://standards.buildingsmart.org/IFC/RELEASE/IFC4/FINAL/HTML/schema/ifcgeometricmodelresource/lexical/ifcrevolvedareasolid.htm), hollow rectangular profile and exact IfcArcIndex Axis reference. The revolution/profile axes lie in the required local plane before the explicit solid/object transformations. It uses the existing circular arc reader, native closed-wall through-bore audit and Manifold connected-solid/mass checks. No new geometry kernel or repaired mesh is used. Plane-angle units are explicitly radians for this source mode; old source modes retain their unit setup.

For radial outside width Wo, normal outside height Ho, inner dimensions Wi/Hi and radius R, independent material area is A=Wo*Ho-Wi*Hi; volume is A*pi*R/2. The radial area second moment J=(Ho*Wo^3-Hi*Wi^3)/12 gives each local in-plane volume-centroid coordinate 2/pi*(R+J/(A*R)). Source frame rotates this centroid and the tight quarter-bend bounds into world coordinates. Native mesh volume, centroid and bounds are compared without widening the existing 0.001 relative-volume or 2e-5 m linear tolerances.

Saved checks include profile/thickness/no-fillet dimensions, profile offset, revolution position/axis/angle, object placement, exact quarter Axis and its endpoint/arc-length correspondence, source dimension/radius metadata, native single connected closed wall/through-bore topology, mass and outward port axes. A body, annotation or arc-reference label alone is insufficient.
