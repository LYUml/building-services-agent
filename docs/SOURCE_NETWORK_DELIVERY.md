# One-command source-native geometry-study delivery

source_network_delivery composes the existing verified source_network_drawing,
deterministic review annotations and ifc_native save/reopen/export/plot adapters.
No new engine, dependency or native runtime is introduced. The actual gap was
manual stage handoff and repeated annotation editing. Existing NumPy, Shapely2.2.0,
IfcOpenShell, ezdxf, AutoCAD and PDF-vector measurement retain their prior licences
and scope. The source model/analysis and original projection are preserved.

```
python -m bsa.source_network_delivery run SOURCE_ANALYSIS --out FRESH_DELIVERY --autocad HOST_EXE
python -m bsa.source_network_delivery verify FRESH_DELIVERY
```

Set host BSA_PROJECT_ROOT for an external project. Source documents cannot select
workspace or executable; the host supplies AutoCAD. Outputs must be fresh and
outside the immutable source analysis. Default review scale is derived from saved
model bounds and A4 space; optional --scale is an explicit host composition choice.
Neither establishes actual surveyed building scale. Invalid or clipped layouts
reject before native writes.

The run replays source/native analysis, exports complete GUID-linked silhouettes,
preserves every requirement ID, creates title/assumption/pending notes and a
labelled model reference, then executes the isolated native adapter. No unsupported
local-loss value, installation dimension, equipment rating or code clause is added.
The saved package records source/method/runtime identities and artifact hashes.
Visual and complete engineering acceptance remain pending after execution.

Independent verification replays original analysis, reconstructs contours from
the original native IFC, rebuilds annotation layout, compares native re-export
entities/identity and remeasures the actual PDF reference. Saved-byte hashes are
not substitutes for native-source geometry correspondence. Separate human visual
review binds the plotted page after rendering; it does not rewrite producer
pending states or accept pressure, installation, product or full regulations.

The complete command begins with an already reviewed source-native analysis.
It does not interpret an arbitrary brief, finish remaining fitting/boundary losses
or certify a complete building-services design. This is one composed delivery
stage within the full original agent objective, not a replacement objective.
