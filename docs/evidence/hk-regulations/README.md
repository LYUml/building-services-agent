# Initial Hong Kong rule-pack evidence

The official EMSD 2025 Wiring CoP PDF was downloaded from its recorded official URL and hash-verified. Code 13A(3)(v), printed page 115 / PDF page 116, was inspected as extracted text and as a locally rendered image. Full PDF and page image remain in runs/hk-regulation-sources, not redistributed. The pinned digest is in the pack and output reports.

Four synthetic project controls against those actual official bytes produce pass, review_required, not_applicable and pending respectively. None reports regulatory compliance or design acceptance. Six automated unit tests cover the 4% boundary, alternatives, source changes, missing evidence/editions, branch-only/transient scope, invalid units and nonfinite values, mismatched jurisdictions and unsupported methods. Unit tests use a clearly labelled synthetic source fixture; they are distinct from the actual-official-PDF controls.

The source inventory covers additional Hong Kong authorities, but only one electrical check is executable. Future pack versions must expand applicability, amendments, multi-domain rules and engineering-data integration; inventory presence is not regulatory coverage.
