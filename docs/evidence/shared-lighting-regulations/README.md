Actual synthetic shared electrical/geometry sources generated per-space BEC office LPD checks using the official hash-pinned source. The same files then produced coordinated DXF and saved/reopened IFC; the existing adapter reconciled device IDs, XY, electrical watts, PF and circuit membership. Three 40 W fixtures in a declared 8 x 6 m room yield 2.5 W/m2. Scope and actual internal-area/driver assumptions remain explicit.

The original-run plan and reports are retained; official PDF is not redistributed. The ZIP retains the generated model and verification artifacts. Four binding tests cover derived full power/area, missing inventory/bases, separate rooms and prohibited overrides/explicit non-light classification; sixteen workflow tests passed. Native DWG, rendering/photometric checks, saved-IFC-to-LPD geometry binding and full compliance acceptance remain pending.
