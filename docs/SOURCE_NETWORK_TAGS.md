# Finite source-network annotation study

`python -m bsa.source_network_tags DELIVERY SCHEDULE --out FRESH_DIRECTORY`
requires a separate fresh host-selected output directory and preserves sources.
It deliberately exits 2: ancestry, native and engineering acceptance are pending.

Existing view_tags/route_annotations checks, Shapely2.2.0 polygons and pinned
SciPy1.18.1/NumPy2.5.4/HiGHS supply the engines. No new dependency or service.
Actual projected polygons and exposed boundary anchors generate finite candidates.
Binary selection requires one tag per GUID and excludes overlaps, leader crossings
and note/reference interference. This finite palette is not an exhaustive proof
of feasibility. Text is 2.5 mm at plot scale; margins are graphic choices, not
regulatory installation clearances.

The private real trial selected102 tags from2568 candidates with30723 conflict
pairs; solver optimality was reported. Independent all-pairs geometry replay
passes. Saved DXF replay preserves292 original model entities/identities and
checks exactly102 new texts/102 leaders against the audited placements. The
rendered preview was inspected without obvious overlap. Three tests pass,
including changed base geometry/identity, bad endpoints/labels, incomplete
coverage and no-space cases. Durable runner and independent receipt verify pass.

Original producer method hashes remain historical and are not rewritten after
adding audit functions. Separate audit records identify the original placement
and current audit method. Source ancestry, actual tagged DWG save/reopen and
fixed-scale PDF review remain pending. This preview is not an accepted design.
